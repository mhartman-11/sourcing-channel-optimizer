# Sourcing Channel Optimizer

Live: https://sourcing-channel-optimizer.vercel.app/

A free tool that helps recruiters find the best channels to source talent. Filter by industry, skills, and role type to get ranked channel recommendations. No login, no paywall.

- Channel recommendations tuned to role type and industry
- Skill and function based filtering
- Open access, built for practitioners

Built with React, TypeScript, Vite, and Tailwind. Deployed on Vercel.
